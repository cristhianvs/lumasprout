# Grow the next discovery

This is a direction, not a promise of delivery dates. The playable prototype and telemetry loop exist today; human learning outcomes still require independent evaluation.

## Available today

- Finite island adventure and six fraction skills.
- Four selectable modalities, independent-response accounting and pedagogical stage coverage.
- Local simulation dashboard and linked adaptation outcomes.
- Automated engine checks and browser-driven behavior scenarios.

## Next milestones

1. **Broader learning content:** reviewed fraction variants, more equivalence denominators, clearer explanations and less similar transfer tasks.
2. **Accessible by design:** keyboard/screen-reader audit, mobile play and reduced-motion review.
3. **A stronger measurement contract:** documented event schema, migration fixtures and observable error cases.
4. **Observed pilot readiness:** reviewed external assessments, observation protocol and appropriate participant data handling.
5. **Evidence-based calibration:** separate development and evaluation data; compare knowledge adaptation with presentation preferences.

## Starter tasks

These are contribution proposals, not work already assigned. Open an issue with the title below so others can coordinate.

| Suggested issue | Good first scope | Acceptance criteria |
|---|---|---|
| Document telemetry schema 1.3 | Documentation/testing | Describe required/optional fields and one synthetic example per event; preserve legacy imports. |
| Audit keyboard focus in the workshop | Accessibility | Reproduce with keyboard, describe focus order, add a targeted fix/test where needed. |
| Prepare an interface-string inventory | Localization | Inventory child-facing Spanish strings and placeholders; no learner-visible language change yet. |
| Review six transfer prompts | Learning design | Explain mathematical intent and potential ambiguity; propose teacher-review criteria. |
| Make browser selection configurable | Developer experience | Preserve current Chrome default; enable an explicit CI browser override and document setup. |
| Improve static alternatives to animated demos | Accessibility/design | Provide descriptive stills with useful alt text and no new external tracking. |

For substantive changes, discuss the design before replacing existing progression or persistence. See [CONTRIBUTING](../CONTRIBUTING.md).
