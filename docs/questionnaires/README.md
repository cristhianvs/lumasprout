# Child feedback questionnaire / Cuestionario infantil

[Download the fillable questionnaire IL-EXP-0.2](IL-EXP-0.2.pdf).

Spanish, intended for ages 10–12. Three child-facing pages and one adult administration guide. Includes four introductory-game questions (start, creatures, signals, garden), followed by twelve experience questions. Blank template only: no participant responses.

This draft standardizes wording and administration; it is **not a validated psychological instrument**. It includes optional/non-exposure answers and should be reviewed for comprehension with participants before stable use. Responses are not automatically sent to the game or a database.

Rebuild using Python with ReportLab: `python scripts/build_child_feedback.py`. The generated file is written to ignored `output/pdf/`; review layout and form fields before replacing the public template. Previous QA checked four pages, 23 fields and 88 widgets, including a fictional fill/read round trip.
